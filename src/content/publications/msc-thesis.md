summary: >-

abstract: >-
  This thesis proposes a new system for unsupervised person tracking by detection. The system
  focuses on tracking players in sports video, specifically floorball, using multiple cameras
  with different viewing angles. The new hard-negative mining technique leveraging time
  constraints enables us to train the identification network without labelled data. The proposed
  method generates tracklets with a low level of ID switches, and it is appropriate for
  generating labelled data for supervised training. Samples from the newly created dataset, which
  we used for evaluation, are attached to the thesis along with the code.
